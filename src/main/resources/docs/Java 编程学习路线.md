# Java 编程学习路线

## 基础阶段
学习 Java 时应先掌握变量、数据类型、运算符、流程控制、方法和数组，再理解类、对象、封装、继承与多态。集合、异常、字符串和日期也是日常开发的基础内容。建议通过计算器、学生管理系统等小练习熟悉语法，不要只看视频或背诵概念，要能够独立编写、运行并修改代码。

## 进阶阶段
基础稳定后，可以学习集合源码、泛型、IO、反射、注解、线程和并发工具，逐步理解 JVM 内存、垃圾回收和类加载机制。同时掌握 MySQL 的表设计、索引、事务与 SQL 优化，了解 HTTP、TCP、Redis 和常见缓存问题，为后续开发后端项目做好准备。

## 项目阶段
掌握 Spring、Spring Boot、MyBatis 或 JPA 后，选择一个真实业务项目进行实践，例如知识库、博客或订单系统。按照需求分析、数据库设计、接口开发、权限控制、异常处理、日志记录、测试和部署的顺序完成项目。每个阶段都要记录问题、解决方案和改进方向，形成自己的学习笔记。

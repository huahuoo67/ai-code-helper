# 程序员常见面试题

## Java 基础
Java 面试通常会考察面向对象、重载与重写、String、集合、异常和泛型等内容。准备时不能只记结论，还要理解 HashMap 的存储过程、ArrayList 的扩容特点以及 equals 和 hashCode 的关系。回答问题时可以结合代码示例，先说基本原理，再说明实际使用场景和容易出现的问题。

## 并发与数据库
并发部分需要掌握线程创建、线程池、锁、volatile、CAS、并发容器和线程安全问题。数据库部分要重点复习索引、事务隔离级别、慢查询、锁和分页查询，并能够解释为什么索引失效。遇到综合题时，应从性能、可靠性、数据一致性和维护成本几个方面分析方案。

## 项目与表达
项目面试不只是介绍项目名称和技术栈，更重要的是说明自己负责的功能、遇到的困难、采取的方案以及最终效果。可以提前准备三分钟项目介绍，并整理接口设计、缓存使用、异常处理和性能优化案例。面对陌生问题时，先明确已知条件，再表达分析过程，比直接猜测答案更容易获得认可。

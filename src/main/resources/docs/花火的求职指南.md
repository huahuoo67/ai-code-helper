# 花火的求职指南

## 简历准备
花火准备简历时，应针对目标岗位突出相关技术和项目成果，不要简单罗列课程、工具或技术名词。项目经历可以按照项目背景、个人职责、技术方案和最终结果进行描述，尽量加入接口数量、响应速度、用户规模或问题解决情况等具体信息，让面试官快速了解个人能力和实际贡献。

## 面试准备
面试前要准备简洁的自我介绍、项目介绍和常见技术问题，并提前了解公司的业务方向和岗位要求。对于项目中的每个模块，都应该能够说明为什么这样设计、还有哪些不足以及未来如何改进。还可以准备几个有质量的反问问题，例如团队协作方式、岗位工作内容和新人培养安排。

## 投递与复盘
投递简历时应根据职位描述调整关键词和项目顺序，记录公司名称、岗位要求、投递时间和面试进度。每次面试结束后，及时整理被问到的问题，区分已经掌握、需要复习和暂时陌生的内容，再制定下一步计划。保持稳定投递和持续复盘，比短时间内盲目投递大量岗位更有效。
